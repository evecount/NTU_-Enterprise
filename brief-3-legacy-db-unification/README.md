# Brief 3: SME Legacy Database Modernization & Record Unification

**Track:** Data Engineering & Database Modernization  
**Duration:** 4 Weeks (Two 2-Week Sprints)

## Objective
Audit, deduplicate, and normalize messy legacy SME client and transaction exports into a unified relational Customer Master Model, complete with an automated before-and-after data-quality scorecard.

## Starter Data
- `data/sample_legacy_clients.csv` — Synthetic, masked legacy client records exhibiting duplicate entities, inconsistent phone/postal formats, missing fields, and dormant/legacy flags.

## Milestones
- **Weeks 1–2:** Data quality profiling, target unified schema design, and fuzzy matching / conflict-resolution rules.
- **Weeks 3–4:** Clean migration into unified SQL schema, automated audit scorecard, and live technical walkthrough.
