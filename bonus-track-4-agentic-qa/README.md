# Track 4 (Bonus Challenge): Agentic Q&A / Operations Assistant

**Track:** Applied GenAI & RAG  
**Duration:** 4 Weeks (Two 2-Week Sprints)

## Objective
Build a grounded internal operations / customer-service Q&A assistant on top of cleaned enterprise datasets (from Briefs 1–3) so staff can query client history, parts/inventory, or SOP protocols in natural language with citations and zero hallucinations.

## Starter Data
- `data/sample_sop_kb.md` — Sample SME standard operating procedures and escalation rules.

## Milestones
- **Weeks 1–2:** Index cleaned records + SOPs; build grounded Q&A endpoint with citation checks.
- **Weeks 3–4:** Add structured lookup tools, factual evaluation tests, and a simple chat UI for live demo.
